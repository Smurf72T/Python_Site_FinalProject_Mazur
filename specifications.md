**Реализуйте в рамках проекта следующие функции сайта:**

1. **Размещение объявления.** Пользователи могут разместить объявление об аренде одежды. В объявлении должно быть:
    - описание объекта;
    - стоимость аренды;
    - местоположение;
    - контактная информация для потенциальных арендаторов.
2. **Поиск объявлений.** Пользователи могут искать объявления по нескольким фильтрам: 
    - по ключевым словам в заголовке/тексте объявления;
    - по местоположению товара;
    - по стоимости аренды.
3. **Редактирование объявления.** Пользователи могут редактировать свои объявления. Менять информацию в объявлении или удалять его, если товар уже сдан в аренду и оно больше не актуально.
4. **Аутентификация пользователей.** Функция предотвратит спам и гарантирует, что только авторизованные пользователи могут размещать объявления или просматривать контактную информацию.
5. **Модерация.** Объявления публикуются на сайте только после того, как проходят модерацию. Это нужно, чтобы на сайте не появлялся спам или неуместные объявления. 
6. **Обратная связь.** Пользователь может оставить отзыв об объявлениях и продавце. Это поможет улучшить качество объявлений и пользовательский опыт.

### Шаг 2. Создайте базу данных
Чтобы хранить объявления, данные пользователей, отзывы и другую информацию, вам понадобится база данных. Создайте базу данных с помощью PostgreSQL.

 <details>
    <summary><strong>Как это сделать</strong></summary>

1. **Установите PostgreSQL.**
   <br>
   <br>
    **Как установить PostgreSQL на Windows**
    - Скачайте нужный дистрибутив PostgreSQL на [официальном сайте PostgreSQL](https://www.postgresql.org/download/windows/).
    - Запустите установочный файл.
    - Выберите компоненты, которые хотите установить.
      
      > Рекомендуем оставить выбранными все компоненты по умолчанию (далее вам понадобится PgAdmin 4).
      
    - Установите пароль для пользователя “postgres” с правами администратора PostgreSQL. Убедитесь, что пароль надежный, и сохраните его в безопасном месте. Он потребуется для доступа к PostgreSQL.
    - Выберите порт, на котором будет слушать PostgreSQL. Оставьте значение по умолчанию (5432) или выберите другой свободный порт, если требуется.
    - Выберите способ аутентификации пользователей PostgreSQL.
      
      > Рекомендуем выбрать способ “Use PostgreSQL's built-in authentication", то есть использовать встроенную аутентификацию PostgreSQL.
      
    - На экране “Select Additional Tasks” (Выбор дополнительных задач) добавьте PostgreSQL в PATH системы и создайте группу программ PostgreSQL в меню «Пуск».
    - Проверьте все настройки и установите PostgreSQL.

    **Как установить PostgreSQL на Linux**
   <br>
   Скачайте PostgreSQL для Linux с помощью стандартных инструментов управления пакетами вашей операционной системы.
   Вот как это можно сделать для дистрибутивов Debian или Ubuntu:
   - Откройте терминал и выполните следующую команду, чтобы обновить список пакетов:
     
      ```
        sudo apt update
      ```

   - Затем выполните следующую команду, чтобы установить PostgreSQL:
     
     ```
        sudo apt install postgresql
     ```

   **Как установить PostgreSQL на MacOS**
   <br>
   Вы можете установить PostgreSQL на macOS, используя Homebrew — менеджер пакетов для macOS. Для этого выполните следующие действия:
   
   - Установите Homebrew, если он еще не установлен, выполнив следующую команду в терминале:
  
        ```
        /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
        ```
    
   - После установки Homebrew выполните следующую команду, чтобы установить PostgreSQL:

        ```
        brew install postgresql
        ```
2. **Запустите PostgreSQL.**
   <br>
   <br>
   **Как запустить PostgreSQL на Windows**
   <br>
   Откройте программу PgAdmin 4. При первом запуске потребуется задать мастер-пароль, который в будущем будет вводиться для входа в программу.

   **Как запустить PostgreSQL на Linux**
   <br>
   Запустите сервер PostgreSQL. Чтобы его запустить, выполните следующие действия:
   - Откройте терминал из аккаунта администратора.
   - Введите команду:
    
        ```sql
        sudo service postgresql start
        ```
    
   - Инициализируйте директорию баз данных на локальном компьютере. Для этого введите команду:
    
        ```python
        $ initdb -D <data_directory>
        ```
    
     где `<data_directory>` — путь к директории, в которой будут храниться базы данных. Замените его на путь к нужной вам директории.
    
   - Чтобы открыть консоль PostgreSQL, наберите `psql` в терминале.
   
    **Как запустить PostgreSQL на MacOS**
   <br>
   Для запуска PostgreSQL выполните следующую команду:
   
   ```bash
   brew services start postgresql
   ```
   
   Эта команда активирует PostgreSQL и настроит его для автоматического запуска при старте системы.

4. **Создайте новую базу данных.**
   <br>
   <br>
   **Как создать базу данных на Windows**
   - Чтобы подключиться к только что созданному серверу, слева выберите `Servers > PostgreSQL`. Введите пароль, который вы задали на этапе установки PostgreSQL.
   - Нажмите на пункт “Databases” левой кнопкой мыши. Затем нажмите на кнопку базы данных в виде цилиндра.
   - Создайте новую базу данных. Введите следующую команду:
  
     ```sql
        CREATE DATABASE mydatabase;
     ```
     
     Замените `mydatabase` на имя вашей базы данных. Запустите команду кнопкой “▶️”.
     
   **Как создать базу данных на Linux**
   <br>
   Создайте новую базу данных. Введите следующую команду в консоли PostgreSQL:

   ```sql
   CREATE DATABASE mydatabase;
   ```

   **Как создать базу данных на MacOS**
   <br>
   Выполните следующую команду, чтобы создать базу данных:

    ```bash
    createdb mydatabase
    ```

   Замените `mydatabase` на имя вашей базы данных.
   
5. **Создайте нового пользователя** с привилегиями для доступа к базе данных. Введите следующую команду в консоли PostgreSQL:
    
    ```sql
    CREATE USER myuser WITH PASSWORD 'mypassword';
    ```
    
    Замените `myuser` и `mypassword` на имя пользователя и пароль, которые вы хотите использовать для пользователя базы данных.
    
    Предоставьте привилегии новому пользователю, введя следующую команду в консоли PostgreSQL:
    
    ```css
    GRANT ALL PRIVILEGES ON DATABASE mydatabase TO myuser;
    ```
    
    Замените `mydatabase` и `myuser` на имя вашей базы данных и имя вашего пользователя, которые вы только что создали.
    
6. **Установите адаптер PostgreSQL для Python** с помощью pip. Выполните следующую команду:
    
    ```python
    pip install psycopg2-binary
    ```
    
7. **Настройте базу данных в проекте Django.** Откройте `settings.py` и найдите настройки баз данных. Замените настройки на следующие:
    
    ```python
    DATABASES = {
        'default': {
            'ENGINE': 'django.db.backends.postgresql',
            'NAME': 'mydatabase',
            'USER': 'myuser',
            'PASSWORD': 'mypassword',
            'HOST': 'localhost',
            'PORT': '5432',
        }
    }
    ```
    
    Замените `mydatabase`, `myuser` и `mypassword` именами и паролем, которые вы выбрали ранее.
    
    Сохраните `settings.py` файл и запустите следующую команду, чтобы создать необходимые таблицы в базе данных:
    
    ```python
    python manage.py migrate
    ```

**Вот и все! Вы успешно создали базу данных PostgreSQL и настроили свой проект Django на её использование.**

### Шаг 4. Определите views или конечные точки
Определите маршруты, шаблоны и формы, чтобы упростить обработку HTTP-запросов от пользователей.

<details>
    <summary><strong>Как определить URL</strong></summary> 
    
В Django маршруты определяются в `urls.py`. Чтобы определить маршруты, выполните шаги ниже. 

1. Откройте `urls.py` файл в каталоге ваших приложений.
2. Импортируйте модуль views из вашего приложения:

      ```python
        from . import views
      ```
  
  Это предполагает, что у вас есть файл `views.py` в папке приложения.
  
3. Определите свои маршруты через переменную `urlpatterns`. Каждый маршрут — кортеж с двумя элементами: шаблоном маршрута и функцией просмотра, которая вызывается при доступе к маршруту.

      ```python
        urlpatterns = [
            path('', views.home, name='home'),
            path('about/', views.about, name='about'),
            path('contact/', views.contact, name='contact'),
        ]
      ```
  
      Определите три маршрута: `корневой URL`, `about` и `contact`. Каждый маршрут связан с функцией просмотра: главная, о проектк и контакт. Параметр `name` необязателен, но упрощает создание URL-адресов в шаблонах.
  
4. Определите функции просмотра в `views.py`. Функция просмотра — это функция Python, которая принимает HTTP-запрос в качестве первого аргумента и возвращает HTTP-ответ.

      ```python
        from django.shortcuts import render
        
        def home(request):
            return render(request, 'home.html')
        
        def about(request):
            return render(request, 'about.html')
        
        def contact(request):
            return render(request, 'contact.html')
      ```

      Используйте render для рендеринга шаблона. Объект HTTP-запрос — первый аргумент визуализации, а имя файла шаблона — второй.
    
</details> 


<details>
    <summary><strong>Как определить шаблон</strong></summary> 
    В Django шаблоны используют для динамической генерации HTML. 

1. Создайте папку для шаблонов внутри папки вашего приложения.
2. Внутри папки `templates` создайте новую папку с именем вашего приложения.
3. Создайте новый HTML-файл внутри папки приложения. Этот файл будет вашим шаблоном.

      ```html
            <!DOCTYPE html>
            <html>
            <head>
                <title>{{ title }}</title>
            </head>
            <body>
                <h1>{{ heading }}</h1>
                <p>{{ content }}</p>
            </body>
            </html>
      ```

      Создайте простой шаблон с заголовком, подзаголовком и содержимым. Обратите внимание на использование двойных фигурных скобок `{{ }}` для обозначения переменных.
  
4. Определите свою функцию просмотра в `views.py` для рендеринга шаблона.

      ```python
        from django.shortcuts import render
        
        def home(request):
            context = {
      ```

      ```python
        from django import forms
        from django.contrib.auth.forms import UserCreationForm
        from django.contrib.auth.models import User
        
        class RegistrationForm(UserCreationForm):
            email = forms.EmailField(required=True)
        
            class Meta:
                model = User
                fields = (
                    'username', 
                    'email', 
                    'password1', 
                    'password2'
                )
        
            def save(self, commit=True):
                user = super(RegistrationForm, self).save(commit=False)
                user.email = self.cleaned_data['email']
        
                if commit:
                    user.save()
        
                return user
      ```
